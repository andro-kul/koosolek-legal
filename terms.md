## 2. Service description

Koosolek allows users to:
- Record audio from meetings on iPhone
- Transcribe audio via OpenAI Whisper API
- Generate structured meeting minutes via OpenAI GPT API
- Export minutes as PDF, Word (RTF), and text files
- Manage action items with Apple Reminders integration
