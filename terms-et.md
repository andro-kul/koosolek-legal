# Kasutustingimused — Koosolek

Viimati uuendatud: 17. mai 2026

## 1. Üldine

Käesolevad kasutustingimused (edaspidi "Tingimused") reguleerivad Koosolek iOS-äpi (edaspidi "Äpp") kasutamist. Äpi arendajaks ja omanikuks on OÜ Vertex Investment, Eesti (edaspidi "Arendaja").

Äpi kasutamist alustades nõustud käesolevate Tingimustega. Kui sa Tingimustega ei nõustu, ära äppi kasuta.

## 2. Teenuse kirjeldus

Koosolek on tarkvara, mis võimaldab kasutajal:
- Salvestada heli koosolekutest iPhone'iga
- Transkribeerida heli OpenAI Whisper API kaudu
- Genereerida struktureeritud koosoleku protokolli OpenAI GPT API kaudu
- Eksportida protokolle PDF, Word (RTF) ja tekstifaili formaadis
- Hallata järgmisi samme integratsiooniga Apple Meeldetuletustesse

## 3. Tellimused ja maksed

### Plaanid

- **Tasuta** (€0) — kõik baasfunktsioonid kasutaja enda OpenAI API võtmega
- **Pro** (€4.99/kuu või €39/aasta) — kõik premium funktsioonid, kasutaja enda OpenAI võti
- **Cloud** (€9.99/kuu või €79/aasta) — 300 min teenuse mahtu kuus, OpenAI võti pole vajalik
- **Cloud Plus** (€19.99/kuu) — 1500 min teenuse mahtu kuus

### Maksetingimused

- Tellimused töötlevad Apple App Store
- Maksed käivad Apple ID-ga, mitte otse Arendajaga
- Tellimused uuenevad automaatselt iga perioodi lõpus, kui sa neid ei tühista
- Tühistamine peab toimuma vähemalt 24h enne perioodi lõppu

### Tagasimaksed

Tagasimaksete poliitika järgib Apple App Store reegleid. Tagasimakse-soove saada Apple'ile. Arendaja ei tee tagasimakseid otse.

### Cloud plaani maht

- Kuumaht ei kandu üle järgmisse kuusse
- Lisamahtu saab juurde osta ühekordsete pakkidega (100 min / 300 min / 600 min / 1500 min)
- Lisamaht ei aegu sama kuu jooksul, kuid kustub plaani tühistamisel

## 4. Kasutaja vastutus

### Aktsepteeritav kasutus

Sa nõustud:
- Salvestama ainult koosolekuid, milleks sul on luba (Eestis nõuab äri-kontekst tavaliselt teiste osalejate teavitamist)
- Mitte kasutama äppi ebaseaduslikuks tegevuseks
- Mitte üritama äpi reverse engineering'ut
- Mitte jagama oma OpenAI API võtit teiste isikutega äpi kaudu

### Salvestamise õiguslikkus

**Sa vastutad ainuisikuliselt selle eest, et koosolekute salvestamine oleks teiste osalejate suhtes seaduslik sinu jurisdiktsioonis.**

Eestis kehtib põhimõte, et võid salvestada vestlust kuhus sa ise osaled, kuid soovituslik on osalejaid sellest teavitada.

Arendaja ei vastuta kasutaja poolt salvestatud heli sisu eest.

### OpenAI API kasutus

Kui kasutad Tasuta või Pro plaani:
- Sinu OpenAI konto on sinu vastutus
- Sinu OpenAI API kulud lähevad otse sinu OpenAI kontolt
- Sinu sisu (heli, tekst) liigub OpenAI'le vastavalt nende poliitikale

## 5. Intellektuaalne omand

Äpi tarkvara, disain, logo on Arendaja omand. Sinu loodud sisu (salvestused, protokollid) jääb sinu omandiks.

## 6. Vastutuse piirang

Arendaja ei vastuta:
- AI poolt valesti tuvastatud sõnumite, nimede või andmete eest
- OpenAI API katkestuste või vigade eest
- Apple App Store maksetehingute eest
- Andmete kaotamise eest (soovitame regulaarselt eksportida)
- Mis tahes kaudse kahju eest, mis tuleneb äpi kasutamisest

Äpp tarnitakse "nagu on" põhimõttel, ilma garantiideta.

## 7. Tellimuse lõpetamine

### Sinu poolt
- Vali iPhone Settings → Apple ID → Subscriptions → Koosolek → Cancel
- Pärast tühistamist säilib praeguse perioodi lõpuni
- Pärast perioodi lõppu lülitub Tasuta plaanile (andmed jäävad alles)

### Arendaja poolt
Reserveerime õiguse blokeerida konto, kui rikud Tingimusi.

## 8. Muudatused

Tingimusi võime aeg-ajalt uuendada. Olulistest muudatustest teavitame äpi sees.

## 9. Kohaldatav õigus ja kohtualluvus

Käesolevatele Tingimustele kohaldub Eesti Vabariigi õigus. Vaidlused lahendatakse Eesti kohtutes.

Euroopa Liidu tarbijatel on õigus pöörduda ODR platvormi kaudu: [ec.europa.eu/consumers/odr](https://ec.europa.eu/consumers/odr).

## 10. Kontakt

- **E-mail**: appfix@vertex.ee
- **Arendaja**: OÜ Vertex Investment
- **Asukoht**: Eesti
